⚙ Cài đặt kết nối Firebase

Dán đối tượng firebaseConfig của dự án (Firebase Console → Project settings → Your apps → Web app). Có thể dán dạng JSON hoặc dạng { apiKey: "...", ... }. Cấu hình được lưu trên trình duyệt này. Nếu bạn đã điền cấu hình trực tiếp trong code (biến FIREBASE_CONFIG) thì không cần nhập ở đây.
